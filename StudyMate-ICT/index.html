      Feature 05
      
            
      Source-grounded learning
      
            
      Ask a question that must be answered only from your notes. StudyMate writes a prompt that forces the AI to admit when the notes do not cover something — instead of guessing.
      
          
      

          
      
            
      
              
      
                
                
              
      
              
      
                
                
              
      
              
      
                
      Offline coverage check
      
                
      
                
      A simple keyword comparison, not an AI judgement. The prompt itself is what controls the answer.
      
              
      
              
      
              
      
                
                
              
      
              
      Required fallback in every answer:
      “The supplied notes do not provide enough information to answer that reliably.”

              Capstone project
              
            
              About StudyMate ICT
              
            
              An AI-assisted ICT learning and study assistant built as a final capstone for the AI and Prompt Engineering internship at Ishvexa Hub.
              
          
              

          
              
            
              
              
              Purpose
              
              
              Beginner ICT students often meet dense technical language before they have the vocabulary to decode it. StudyMate ICT closes that gap with structured, level-aware prompts that turn a topic into a teaching sequence — and with an offline glossary and planner that work without any AI at all.
              
              
              What it demonstrates
              
              
                
                
              • Prompt engineering: explicit roles, inputs, constraints, output contracts and refusal rules.
                • 
                
              • Source-grounded answers: notes as the only permitted evidence, with a fixed refusal sentence.
                • 
                
              • Handling incomplete information: validation, empty states and honest fallbacks.
                • 
                
              • Responsible AI: no fabricated sources, no fake AI responses, no hidden API keys.
                • 
              
              
              
              Technology
              
              
              HTML5, modern CSS3 and vanilla JavaScript. No framework, no build step, no database, no account. Saved items use LocalStorage only.
              
            
              
            
              
              
              AI status: prompt mode
              
              
              This build never calls an AI service.
              
              
              There is no API key in the source and no network request is made. StudyMate builds high-quality prompts; you decide where to run them. This is a deliberate design choice: it keeps the project free, safe to demonstrate offline, and impossible to mistake for an “answer machine”.
              
              
              Responsible use
              
              
                
                
              • Check AI output against class notes, textbooks or your lecturer.
                • 
                
              • Do not paste private or confidential information into external AI tools.
                • 
                
              • Use generated quizzes to test yourself — not to replace studying.
                • 
                
              • Follow your institution's rules on AI assistance.
                • 
              
              
            
              
          
              

          
              
            
              Honest limitations
              
            
                
              
              • No AI model is connected, so the app cannot produce answers by itself — by design.
                • 
              
              • Prompt quality depends on the notes and topic you supply.
                • 
              
              • The planner is a simple minutes-and-blocks scheduler, not an optimiser.
                • 
              
              • LocalStorage holds roughly 5 MB and is per-browser; it is not a backup.
                • 
              
              • The glossary is a curated starter set, not a complete ICT dictionary.
                • 
            
              
            
              Full detail: LIMITATIONS_AND_FUTURE_WORK.md in the project folder.
